# Create & View Digital Objects (DOB)

This project is my submission for the CKB "Create a DOB" campaign. It's a simple dApp
that creates and displays a Digital Object (DOB) on the CKB blockchain using Spore-SDK,
following the official [tutorial](https://docs.nervos.org/docs/dapp/create-dob).

## What Was Done

By following the CKB tutorial, I successfully completed the following steps:
*   Set up my local development environment using the `@offckb/cli`.
*   Started a local CKB Devnet and accessed pre-funded test accounts.
*   Ran the local dApp environment using `parcel`.
*   Minted an on-chain digital object (DOB) containing an image using the Spore-SDK (`createSporeDOB` function).
*   Fetched and rendered the on-chain digital object data directly in the browser.
*   Deployed the application to the testnet.
